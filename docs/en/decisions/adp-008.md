# ADP-008 — Scoping Language Release v0.1.0

- **Status**: Approved & In Progress
- **Deciders**: Poppy Team
- **Phase**: Wave 6 (P05)

---

## Context

Following the completion of Waves 0 through 5, it was essential to establish an uncompromising boundary for the initial public stable release (`v0.1.0`), preventing scope creep and distraction into tangential tooling.

---

## Decisions Taken

1. **Language-First Strategy**:
   - The focus of v0.1.0 is exclusively the **standalone programming language** and its core CLI toolchain.
2. **In Scope for v0.1.0**:
   - Complete compiler and virtual machine.
   - Standard library with VM ↔ JS differential parity.
   - Unified CLI tool (`aipo run`, `check`, `build`, `disasm`, `fmt`, `package`).
   - Minimalist test runner.
   - Synchronous versioned C ABI (ADP-009) and thin proofs (ADP-010).
3. **Deferred Post-v1.0**:
   - Full Godot integration and Petunia3D game engine.
   - Centralized public package registry in the cloud.
   - Visual node editors and heavy IDE language server protocols.

# ADP-006 — Open Decisions for Waves 3 & 4

- **Status**: Approved & Implemented
- **Deciders**: Poppy Team
- **Phase**: Waves 3 and 4 (P02 / P03)

---

## Context

Consolidation of open design decisions regarding asynchronous concurrency, task combinators, and Host ABI capability scoping.

---

## Decisions Taken

1. **Concurrency Syntax**:
   - `await` restricted to dedicated `await do ... end` execution blocks.
   - Forbids arbitrary `await` inside arithmetic subexpressions to prevent invisible data races.

2. **Cooperative Scheduler**:
   - Deterministic virtual time managed by runtime.
   - Cooperative fibers switching at designated safe points.

3. **Capability Trees in Host ABI**:
   - Hierarchical path notation for system permissions (e.g., `fs.read`, `fs.write`, `net.http`).
   - Strict deny-by-default capability model.

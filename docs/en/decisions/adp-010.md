# ADP-010 — Thin Interoperability Proofs (Rust, C, JS)

- **Status**: Approved & In Implementation
- **Deciders**: Poppy Team
- **Phase**: Wave 6 (P05)

---

## Context

Ensure that v0.1.0's promise of cross-ecosystem interoperability is not merely theoretical, but validated by automated tests running across each supported language environment.

---

## Decisions Taken

1. **Proof 1 — Rust Embedding**:
   - Integration test fixture in `tests/` demonstrating initializing an `aipo_vm::Vm` instance, passing native Rust arguments, and extracting computed results.
2. **Proof 2 — C Host Embedding**:
   - Minimal C executable linking against the compiled static/dynamic library, compiling an Aipo source string, and extracting return values.
3. **Proof 3 — JavaScript/Node.js Host**:
   - A Node.js module importing output produced by `aipo-js`, verifying smooth interoperability within modern npm environments.

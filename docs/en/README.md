# Aipo English Documentation

This directory contains the English (`en-US`) localization of the official Aipo documentation website.

## Directory Structure

- `getting-started/`: Quick start tutorials, installation guides, and CLI introduction.
- `manual/`: Complete reference manual of language syntax, types, control flow, functions, contracts, async, stdlib, and package management.
- `trajectory/`: Historical record of all development waves (Wave 0 through Wave 6).
- `architecture/`: Compiler frontend, VM, bytecode format, JS emitter, Host ABI, and workspace crates.
- `decisions/`: Architectural Decision Proposals (ADP-001 through ADP-011).
- `evidence/`: Cross-language benchmarks, optimization post-mortems, conformance matrix, and slice reports.
- `governance/`: Prumo CLI governance, LPC methodology, code standards, security model, and changelog.

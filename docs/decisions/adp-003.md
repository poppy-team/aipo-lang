# ADP-003 — Orçamentos de Execução

- **Status**: Aprovado & Implementado
- **Decisores**: Poppy Team
- **Fase**: Wave 1

---

## Contexto

Para executar scripts não-confiáveis em ambientes hospedeiros (sandboxing de jogos, plugins ou automações), é fundamental impedir laços infinitos que travem a aplicação.

---

## Decisões Tomadas

1. A VM suporta a configuração opcional de um limite máximo de instruções executadas (*gas / instruction budget*).
2. Cada ciclo de despacho na VM desconta passos do orçamento quando ativo.
3. Se o limite for atingido, a execução é interrompida determinísticamente com o erro `AIPO_RT_BUDGET_EXCEEDED`.
